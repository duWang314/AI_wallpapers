# Neon Nexus 互动桌面壁纸

一个以赛博朋克为主题的 HTML/CSS/JavaScript 动态壁纸，拥有霓虹城市天际线、动态星河、实时信息 HUD 与可调控的交互面板。直接在任何现代浏览器中打开即可展现酷炫效果，适合搭配壁纸引擎或作为全屏 Web 壁纸使用。

## ✨ 功能亮点

- **动态 HUD 仪表板**：展示实时系统时间与日期、虚拟电量条以及可刷新的一句话讯号。
- **霓虹城市视差效果**：多层城市剪影与地平线光栅随鼠标/设备重力感应产生视差漂移。
- **星空粒子场**：自适应画布实现的星流动画，分辨率越高星数越多。
- **交互控制面板**：
  - 自定义霓虹主色调（立即应用至整套光效）。
  - 调整视差强度，适配不同显示器或个人偏好。
  - 开关整体脉冲动画（暂停/恢复霓虹脉冲、城市漂移与漂浮光球）。
  - 开关颗粒噪声覆层，打造更纯净或更复古的视觉效果。
  - 一键刷新讯号文案，获取下一条随机激励语。
- **响应式布局**：在 4K 显示器或窄屏幕上均能自适应排布，随时可全屏展示。

## 🚀 快速体验

1. 双击或拖放 `index.html` 至浏览器（Chrome/Edge/Firefox 最新版皆可）。
2. 将浏览器切换为全屏模式（`F11` 或 `Fn + F11`）。
3. 使用右侧控制面板微调效果，打造你的专属桌面。

> 提示：若使用壁纸引擎（如 Wallpaper Engine、Lively Wallpaper 等），只需导入整个文件夹并指定 `index.html` 即可。

## 🛠️ 自定义建议

- **初始颜色**：修改 `styles.css` 顶部 `:root` 内的 `--accent` 变量即可调整默认霓虹色。
- **引用字体**：默认使用 Google Fonts 的 Space Grotesk，如需离线部署可下载字体文件并本地引入。
- **文案池**：在 `script.js` 中编辑 `quotes` 数组即可更换或扩充随机讯号内容。
- **粒子密度**：调整 `starfield` 渲染函数内的 `totalStars` 计算方式，可增减星星数量。

## 🧪 兼容性

- 建议使用 Chromium 79+ 或 Firefox 78+ 浏览器。
- Battery API 在部分桌面浏览器可能返回 `Promise` 拒绝，此时脚本会自动回退为平滑的虚拟电量模拟。
