# 🎨 炫酷交互式桌面壁纸

一个使用 HTML、CSS 和 JavaScript 创建的炫酷、可互动的桌面壁纸应用。

## ✨ 功能特点

### 🎯 核心功能
- **动态粒子系统** - 随机生成的粒子在屏幕上漂浮，创造梦幻效果
- **鼠标交互** - 粒子会被鼠标排斥，创造动态交互体验
- **数字时钟** - 实时显示当前时间和日期，带霓虹发光效果
- **涟漪效果** - 点击屏幕产生炫酷的涟漪动画
- **主题切换** - 支持深色/浅色主题切换

### 🎮 交互操作
- **鼠标移动** - 粒子会躲避鼠标，自定义光标跟随
- **鼠标点击** - 创建涟漪效果
- **空格键** - 切换深色/浅色主题
- **K键** - 触发烟花特效（彩蛋）
- **P键** - 切换性能模式

### 🎨 视觉效果
- **渐变背景** - 动态颜色渐变背景动画
- **故障艺术文字** - CYBER SPACE 标题带故障效果
- **霓虹发光** - 时钟和文字的霓虹灯效果
- **粒子连线** - 相近粒子之间自动连线
- **混合模式** - 光标使用差值混合模式

## 🚀 使用方法

### 直接打开
1. 双击 `index.html` 文件
2. 在浏览器中打开即可使用

### 作为桌面壁纸
#### Windows (使用 Wallpaper Engine)
1. 安装 Wallpaper Engine
2. 创建新的网页壁纸
3. 指向 `index.html` 文件

#### 使用 Lively Wallpaper (免费)
1. 下载并安装 Lively Wallpaper
2. 点击 "+" 添加壁纸
3. 选择 "网页" 类型
4. 浏览并选择 `index.html` 文件

### 本地服务器运行
```bash
# Python 3
python -m http.server 8000

# Node.js (需要安装 http-server)
npx http-server

# 然后访问
http://localhost:8000
```

## 🎯 性能优化

- **自适应粒子数量** - 根据屏幕大小自动调整粒子数量
- **页面可见性API** - 页面隐藏时暂停动画
- **性能模式切换** - 按P键切换低性能模式
- **requestAnimationFrame** - 使用浏览器优化的动画帧

## 📱 响应式设计

支持不同屏幕尺寸：
- 桌面显示器
- 笔记本电脑
- 平板电脑
- 手机（支持触摸交互）

## 🛠️ 技术栈

- **HTML5** - 页面结构
- **CSS3** - 样式和动画
- **JavaScript (ES6)** - 交互逻辑
- **Canvas API** - 粒子系统绘制

## 📝 自定义修改

### 修改颜色主题
编辑 `style.css` 中的渐变背景：
```css
.gradient-bg {
    background: linear-gradient(45deg, #1a0033, #330066, #4d0099, #6600cc);
}
```

### 调整粒子数量
编辑 `script.js` 中的粒子生成：
```javascript
const particleCount = Math.floor((window.innerWidth * window.innerHeight) / 10000);
```

### 修改时钟格式
在 `script.js` 的 `DigitalClock` 类中修改时间格式
