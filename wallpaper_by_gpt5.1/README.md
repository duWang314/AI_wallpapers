# 炫酷交互桌面壁纸

使用 HTML + CSS + JavaScript 编写的炫酷电脑桌面风格页面，包含：

- 动态粒子背景 + 连接线星空
- 玻璃拟物风格时钟、系统节奏（CPU/内存/网络）指示条
- 互动星轨（可随时间旋转，响应鼠标）
- 支持拖拽卡片布局、双击空白区域重置布局
- 支持一键切换霓虹 / 日落主题、暂停或恢复动画

## 运行方式

直接用浏览器打开 `index.html` 即可预览。

建议开启浏览器全屏模式（`F11`），获得接近桌面壁纸的沉浸体验。

如果你使用 Wallpaper Engine、Lively Wallpaper 等工具，可以直接加载整个文件夹作为 HTML 壁纸源。
