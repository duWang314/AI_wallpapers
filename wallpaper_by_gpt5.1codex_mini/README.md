# Neon Pulse Desktop Wallpaper

这个项目提供一张使用 `HTML`、`CSS` 与 `JavaScript` 打造的交互式桌面壁纸，适合在浏览器全屏模式或网页壁纸工具中启用。

## 运行方式
1. 确保安装了 Python（或其他可提供静态服务器的环境）。
2. 在项目根目录运行：

```cmd
cd c:\Users\Administrator\VscodeProjects\AI_wallpapers\wallpaper
python -m http.server 3000
```

3. 打开浏览器访问 `http://localhost:3000` 并全屏显示即可将页面作为桌面壁纸背景。

> 鼠标移动时光点会实时响应，底部按钮切换不同光感模组。
